# 图标悬停循环动效

## Brief

- 性格：轻盈、克制、流畅。沿用蓝白玻璃底座和现有 Lucide 线条，不改变文字、卡片尺寸和布局。
- 范围：左上角品牌图标，以及总览、投递台历、我的投递、Offerbiu、简历管理、代码手撕的标题图标，共七个。
- 使用方式：鼠标悬停持续循环；移开后从当前帧在 220ms 内平滑回到原样。不会自动播放；切页、隐藏页面、减少动态效果时停止。
- 几何来源：原页面实际渲染的 SVG。直接复用矢量路径，无位图描摹；仅分组并命名动画部件。新增纸片只在动作期间出现，静态透明。
- 复杂度：圆角矩形、直线、原始少量曲线路径。保持 24×24 viewBox、24px 图标尺寸、2px 圆头线条。原始路径记录在本地 QA 的 source-icons.json。

## Timeline and principles

所有部件共用 2200ms 时钟。约 20% 预备、50% 动作、30% 回落与停顿；总览方格、日期点和文档行错开起止时间。底座只上移 2px、均匀放大 2%，不挤压布局。

- Staging：每种图标只有一个主动作，其他部件轻微跟随。
- Slow in/out：所有段使用 cubic-bezier(.4, 0, .2, 1)，实际应用于 Web Animations 关键帧，避免变量在 CSS 关键帧内失效。
- Timing：2200ms 一轮，幅度小，尾部留出静止时间。
- Follow-through：提手先动、包身后动；方格、装订环、文字行分批跟随。
- Appeal / solid drawing：保留原始轮廓，使用变换与透明度；首尾完全一致，无旋转整页或文字位移。

## Interaction / accessibility

- 同一图标最多一组循环。快速移入时，从尚未结束的归位动画当前帧接续，不跳回起点。
- 鼠标离开：读取每个部件的实际 transform / opacity，取消循环，再从该帧回落；完成后取消归位动画，不保留额外变换。
- 图标不是按钮，不添加多余 Tab 停靠或点击行为。已有可聚焦父控件支持 focus-visible；展示页的真实按钮可用键盘预览。
- prefers-reduced-motion: reduce：立即静态；偏好实时改变时也停止。
- 页面隐藏、窗口失焦或栏目切换时释放动画，避免后台循环。

## Preview and QA

打开 logo_motion.html 可悬停查看全部图标；包括 Replay、慢放、即时速度控制和三个部件研究。

- ?static=1：全部静态。
- ?t=毫秒：同一时钟的确定帧，?t=2200 与静态帧完全一致。
- 0/2200ms 是完成归位并释放动画层的端点；2199/2201ms 保留连续循环，用于单独检查接缝。浏览器动画合成层可能让渐变/阴影产生小于一个色阶的平均误差，因此最终静态比较必须包含正式移开后同样的动画层释放。
- ?qa=1：隐藏控件与文字，仅显示固定大小的七图标条，用于原始轮廓、静态、循环接缝和动作帧对比。
- ?reduced=1：展示页模拟减少动态效果，正式页面仍遵守系统偏好。
- window.__p2mReady：预览加载并定位到指定时刻之后为 true。

QA 证据保存在本地 output/icon-motion/，不改变记录文件，不上传 tests 或预览截图。

## 本轮验证结果

- 原始 SVG 与结构化 SVG 的静态浏览器截图：0 像素差异；白色前景 IoU = 1.000，原始轮廓直接复用，一轮接受。
- 归位完成端点（2200ms）与静态：0 像素差异。连续循环 2199ms / 2201ms：0 像素差异。
- 方格动作进度 25% / 50% / 75% 对应实际位移 0.236587 / 0.775561 / 0.959368px，符合设计缓动，未退化为线性。
- 纸片入箱在 930–1050ms 每 10ms 采样：像素变化连续，平均差值约 1.72–2.62，无停顿后突跳。
- 237 项本地测试通过；真实浏览器验证了七图标接入、持续循环、系统偏好即时停止、预览 0.25× 实时调速。
- 静态稿和预览按生产界面真实 24px 图标尺寸展示，另以 192px 真实矢量渲染检查曲线，不从小位图放大判断边缘。
