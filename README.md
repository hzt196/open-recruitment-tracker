# 秋招进度 · Open Recruitment Tracker

一个在浏览器中使用的求职记录工具，用来整理投递进度、笔试与面试安排、Offer、简历和算法练习代码。支持电脑和手机布局，无需安装前端依赖或配置数据库。

## 功能

- **总览**：查看投递数量、面试数量、简历通过率、投递挂率、Offer 数量、阶段分布和近期提醒；可补充招聘 APP 投递数量。
- **投递台历**：按月汇总投递、笔试、面试、Offer、截止及入职事项，区分仅日期事项与具体时刻。
- **我的投递**：新增、编辑、搜索、筛选、排序和收藏岗位，记录 JD、备注及各轮安排；支持复制、删除和短时间撤销。
- **Offerbiu**：整理薪资、日期、状态和备注，填写五险一金参数后预估到手薪资，并横向对比 Offer。估算结果仅供参考。
- **简历管理**：切换中英文 HTML 简历，预览或独立打开文件。
- **代码手撕**：按题目保存 Python 或 C 代码，提供语法高亮、自动补全、标准输入与 Python 运行、编译检查；暂不提供判题或 C 运行功能。
- **数据备份**：通过“导出all / 导入all”保存和恢复 JSON，投递与代码题目分别备份。

## 开始使用

下载仓库并解压，保留原有目录结构。在项目根目录打开终端；如果已安装 Python，可运行：

```sh
python -m http.server 8000 --bind 127.0.0.1
```

然后在浏览器打开 [http://127.0.0.1:8000](http://127.0.0.1:8000)。也可以使用其他静态文件服务器。

直接双击 `index.html` 也可打开页面，但浏览器对 `file://` 的限制可能影响自动读取 JSON 和简历预览；无法自动载入备份时，可手动使用“导入all”。推荐通过本地服务器使用。

图表、部分图标和 Python 运行环境会从 CDN 加载，需要网络连接；Python 首次启动可能需要较长时间。若运行环境加载失败，请检查网络和浏览器限制。

## 目录结构

```text
open-recruitment-tracker/
├── index.html               # 网页入口
├── favicon.ico              # 浏览器标签页图标
├── assets/                  # 样式、脚本及编辑器资源
├── data/
│   └── code_records.json    # 随仓库提供的代码题目记录
├── resume/
│   └── .gitkeep             # 空目录占位文件，不包含实际简历
└── README.md
```

网页使用预构建的编辑器资源，日常使用不需要 `node_modules`、`scripts` 或测试文件夹。

## 数据如何保存

点击“保存”后，记录保存在当前浏览器的 **localStorage** 中。代码编辑器的暂存草稿与正式保存记录分开，只有正式保存的题目会进入导出内容。

浏览器之间不会自动同步；更换浏览器、访问地址或端口时，也可能使用不同的存储空间。清除浏览器数据前，请先导出备份。

“导出all”分别生成：

| 文件 | 内容 |
| --- | --- |
| `records.json` | 投递记录、Offer 信息及招聘 APP 补充投递数量等 |
| `code_records.json` | 已保存的代码题目，包括完整代码、换行、缩进、语言、题目链接和标准输入 |

浏览器支持文件夹写入时，可选择项目文件夹，将备份写入 `data/`；否则会发起下载，需要自行保存文件。普通下载提示不代表文件已成功写入。

使用“导入all”可以选择其中一个 JSON，或同时选择两个恢复数据。JSON 文件只是备份，网页中的编辑不会自动修改仓库或提交到 GitHub。

**公开仓库不提供个人投递备份 `data/records.json`。** 首次打开时投递列表为空，招聘 APP 补充数量按 0 处理；由于该文件不存在，可能出现备份加载提示或 404。可以自行新增岗位、导入自己的备份，或导出后将 `records.json` 放入本地 `data/`。

已有浏览器缓存优先于仓库中的初始备份；更新代码题目 JSON 后，如需在已有浏览器中恢复该版本，请使用“导入all”。

## 放置自己的简历

将 HTML 简历放入本地 `resume/` 目录：

```text
resume/中文.html
resume/english.html
```

在“简历管理”中选择对应语言即可预览和打开。若 HTML 引用了图片、样式或其他资源，也需要一并保留，并检查相对路径。

如需使用其他文件名，可修改 `index.html` 中对应的 `data-resume-path`，以及默认中文简历的打开链接和文件位置说明。

仓库只有 `.gitkeep` 占位文件，未放入个人简历前，对应预览文件不存在。自己的简历和投递备份请保留在本地；发布公开仓库前检查是否包含个人信息。

## 说明

- 本项目是静态网页，不提供账号系统或服务器端数据同步。
- Python 在浏览器的 Worker 中运行，使用 Pyodide；不能视为与本机 Python 完全一致的环境。
- 源码和资源位于 `index.html`、`assets/`，编辑器内置组件的第三方许可说明见 `assets/code-editor.LICENSE.txt`。
